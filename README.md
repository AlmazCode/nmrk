# National Museum of the Republic of Kazakhstan — Website

A static HTML website for the National Museum of the Republic of Kazakhstan, built as part of the **Introduction to Web Technologies** coursework (Assignment 1).

## Theme

**National Museum of the Republic of Kazakhstan** — the largest and youngest museum in Central Asia, located on Independence Square in Astana.

- **Address:** Astana, 54 Tayelshizdik Avenue
- **Phone:** +7 7172 91 90 35 | +7 7172 91 90 36
- **Email:** ulttyk_muzei@nmrk.kz

## Pages

| Page | Description |
|---|---|
| `index.html` | Homepage with welcome message and services overview |
| `history_of_museum.html` | History, architecture, and mission of the museum |
| `exhibits.html` | Featured exhibits: Golden Man, Balbals, Saukele, Otrar ceramics |
| `museum_rules.html` | Visitor rules, prohibited items, and feedback form |
| `visiting_tickets.html` | Ticket prices, discounts, and online booking form |
| `events_programs.html` | Upcoming exhibitions, workshops, lectures, and family programs |
| `colophon.html` | Technical details about how this site was built |

## Technologies

- Pure HTML5 — no CSS, no JavaScript, no frameworks
- Semantic markup (header, nav, main, section, article, aside, figure, table, dl)
- Responsive viewport meta tag
- W3C-compatible markup

## How to View

Download or clone this repository, then open any `.html` file directly in your web browser. No server required.
