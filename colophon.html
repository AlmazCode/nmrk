How This Site Was Built

This project was created as part of the Introduction to Web Technologies coursework. The website strictly adheres to standard HTML markup without any styling frameworks, external CSS sheets, or JavaScript scripts. It demonstrates clean document structure, semantic element selection, and cross-browser accessibility.

To verify page integrity, execute the local validation check using the following terminal command:

npm test or run code validation through W3C Validator Engine. 


<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Validation Sample</title>
  </head>
</html>

Every structural decision was made to prioritize accessibility and raw browser interpretation prior to introducing visual presentation layers in subsequent course modules.

Markup Compliance

Environment Parameters: UTF-8 encoding, responsive viewport meta configuration, and valid HTML5 doctype declaration.

Special characters utilized in this build include &, <, >, and " for safety.
